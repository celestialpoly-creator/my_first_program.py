# my_first_program.py
This is my very first independent Python project, written 100% from scratch without any AI assistance.

What started as a basic homework assignment—to simply take a user's input and check its data type—I decided to push a bit further. I upgraded it into an advanced version that doesn't just check basic types, but precisely identifies if the input is a numeric value, alphabetical string, alphanumeric, decimal, empty space, negative number, or a special character.

Features:

Takes dynamic user input.

Uses Python's built-in string methods (.isdigit(), .isalpha(), .isalnum(), etc.) for fast validation.

Handles negative numbers and floating-point conversions using try-except blocks.
